Klasifikasi Tingkat Stres Mahasiswa Menggunakan Random Forest

Deskripsi

Repository ini berisi program penelitian tugas akhir untuk mengklasifikasikan tingkat stres mahasiswa menggunakan algoritma Random Forest dan optimasi hyperparameter dengan GridSearchCV.

Tujuan

Penelitian ini bertujuan membandingkan performa model Random Forest baseline dengan model Random Forest hasil optimasi hyperparameter.

Berkas Penelitian

* FIXX.ipynb: notebook program penelitian.
* requirements.txt: daftar pustaka Python yang diperlukan.
* Dataset penelitian: tersedia melalui tautan dataset yang dicantumkan pada bagian berikut, apabila diizinkan untuk dibagikan.

Dataset

Dataset yang digunakan merupakan dataset penelitian mengenai faktor-faktor tingkat stres mahasiswa.

Metode

1. Memuat dan mempersiapkan dataset.
2. Melatih model Random Forest baseline.
3. Melakukan optimasi hyperparameter menggunakan GridSearchCV.
4. Mengevaluasi model menggunakan rancangan validasi silang yang digunakan dalam penelitian.
5. Membandingkan performa model berdasarkan metrik evaluasi.
6. Melakukan pengujian McNemar Exact Test dan analisis Permutation Importance apabila tersedia dalam program final.

Cara Menjalankan

1. Siapkan Python dan Jupyter Notebook.
2. Instal pustaka yang tercantum dalam requirements.txt.
3. Unduh dataset dan tempatkan pada lokasi yang sesuai dengan kode program.
4. Buka FIXX.ipynb.
5. Sesuaikan lokasi berkas dataset jika diperlukan.
6. Jalankan sel notebook sesuai urutan.

Catatan

Hasil program mengikuti dataset, konfigurasi eksperimen, dan lingkungan perangkat lunak yang digunakan. Perbedaan versi pustaka atau pengaturan eksperimen dapat memengaruhi hasil yang diperoleh.
